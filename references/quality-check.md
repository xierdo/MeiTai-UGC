# Pre-delivery review

Fail and revise if any critical item below is violated. No numerical quality score or claim of guaranteed conversion. Report only meaningful caveats to the user.

1. Intent: number, duration, scenario, products, reference order, language and character count satisfy user request.
2. Marketing: one coherent audience hypothesis; visible opening; spoken hook adds information; product appears for a reason; payoff and action fit awareness and format. No unverified superiority or manufactured urgency.
3. Reference fidelity: independently identify each supplied image, exact packaging and texture where shown, correct hand scale; no mismatched SKU, mannequin face, invented cap or label.
4. Physical plausibility: camera ownership and hands make sense; no teleportation, impossible transitions, abrupt hair density/haircut change. Correct washing/rinsing/drying and product usage; unknown instructions are omitted or flagged. Time intervals are contiguous and add up exactly.
5. Thai: exact dialogue, correct speaker, tone/register, short enough for the time slot, pauses; Chinese translation is outside prompt. Text-only review is not a native speaker verification.
6. Visual clarity: show intended texture or condition, same conditions for comparisons, payoff has sufficient screen time. No dependence on smiles/lighting alone. If needed, recommend separate assets and edit comparisons.
7. Advertising truthfulness: use substantiated cosmetic claims and current applicable Thai/platform rules when needed; no fake evidence, miracle cures, fabricated studies, promotions, prices, guarantees, retailer affiliations, real-person endorsements or testimonials. A fictional recommendation must be identifiable as a dramatization in the published content; do not present generated results as genuine proof. Disclose AI-generated content using platform tools and/or clear on-screen notice as applicable. For formal claims or legal/platform questions check current official guidance; this checklist is not legal advice.
8. Format/length: prompt standalone, concise, negatives included, count exact output with script where cap requested. Re-count after edits. Local Unicode counts may differ from platform limits; leave margin. If platform uses bytes, use byte count explicitly. No unsupported claims about model capabilities.

## Post-generation review (when footage is provided)
Inspect actual frames/clips rather than inferring quality from prompt. Identify failure by shot: identity, shape, product, liquid, hair, hands, Thai, continuity, compliance. Distinguish visual acceptance from claim substantiation. Fix by replacing problematic clip or reference first; do not keep appending synonyms. Preserve good clips. Do not assert visual inspection of unavailable video.
